# Уязвимости

Нашли, как через шлюз попасть туда, куда не должны, — в пульт без входа, на колонку, к ключам, к записям или
сообщениям? Не пишите в issue: сообщите правообладателю закрыто — hello@duowave.app или через «Report a vulnerability»
на вкладке Security этого репозитория. Ответим в течение недели и договоримся, когда рассказать.

*Found a way past the gateway's access rules, onto a station, or to keys, recordings or messages? Please report it
privately — hello@duowave.app or GitHub's «Report a vulnerability» — not in an issue.*

Что важно для этого проекта:

- **Колонка.** SSH колонки по вики открыт без пароля для всей домашней сети. Шлюз заходит на колонку только по нажатию
  администратора и после показанного заранее списка изменений; ключ хоста колонки он запоминает при первом входе.
- **Пульт и API** отвечают из дома; снаружи — только если владелец это включил (`PANEL_REMOTE`).
- **Секреты** (ключи моделей, токены) хранятся в базе зашифрованными; ключ — в своём файле рядом с базой.
- **Журнал** заменяет идентификаторы колонки и аккаунта хэшами (`RECORDER_REDACT`); звук запросов по умолчанию не
  пишется.

Поддерживается последняя выпущенная версия.
