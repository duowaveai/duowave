# Asterisk для своих звонков

SIP-сервер для звонков без Яндекса (этап 7 плана интеграции):

- телефоны семьи — SIP-приложения (Linphone, Zoiper) с учётками `101`, `102`… из `pjsip.conf`;
- звонок на `100` уходит шлюзу (приложение Stasis `duowave`), шлюз объявляет его на колонке, «Алиса,
  ответь» соединяет;
- «Алиса, позвони маме» — шлюз набирает номер контакта через ARI;
- звук между Asterisk и шлюзом — RTP `slin16` на порт RTP шлюза (по умолчанию 40000);
- настоящие номера — транк SIP-оператора в том же `pjsip.conf` (оператор — открытое решение).

Запуск: скопировать `pjsip.conf.example` и `ari.conf.example` без `.example`, задать пароли,
`docker compose up -d`. Дальше — пульт шлюза, «Дом» → «Коннекторы» → «Телефония (SIP)»: адрес ARI
(`http://127.0.0.1:8088`), логин и пароль из `ari.conf`, адрес шлюза для звука (этот Mac, как его видит контейнер),
контакты — имя и номер; «Проверить» спросит версию Asterisk. Перемены — сразу, без перезапуска шлюза. Переменные
`ARI_*`, `SIP_*` в `.env` шлюз читает только при первом запуске. Файлы с паролями в git не попадают.
