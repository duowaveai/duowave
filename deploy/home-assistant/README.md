# Дополнение для Home Assistant

У кого есть Home Assistant, у того уже есть машина, которая включена всегда. Дополнение — тот же образ шлюза
(`Dockerfile.prod`: программа `duowave` с пультом внутри, Alpine), в сети хоста: поиск колонок по mDNS, звонки и
порт шлюза (7780) работают как на обычном компьютере. Своё в дополнении — только `run.sh`: порт из настроек дополнения,
данные в `/data`, обновления ставит Home Assistant (шлюз о них только сообщает); `run.sh health` — проверка
здоровья на том же порту.

Поставить, пока нет репозитория дополнений:

1. Скопируйте папку `duowave/` в `/addons/` Home Assistant (дополнения Samba или SSH).
2. «Настройки» → «Дополнения» → «Магазин» → ⋮ → «Проверить обновления»: дополнение появится в «Локальных».

`build.yaml` берёт за основу опубликованный образ шлюза: адрес в нём — заглушка, пока нет публичного репозитория и
выпуска. Позже дополнение переедет в свой репозиторий дополнений (`repository.yaml`), и его будут добавлять по
ссылке.

Пульт внутри Home Assistant (ingress) пока не работает: пульт ждёт свои пути от корня (`/panel`, `/api`). Он
открывается по «Открыть веб-интерфейс».
