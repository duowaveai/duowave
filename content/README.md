# Наш контент для плеера колонки

Шлюз отдаёт файлы этой папки по `/media/<путь>` (с `Range`), колонка играет их своим плеером по ссылке из
`audio_play`. Папка задаётся `CONTENT_DIR`.

- `radio.json` — радиостанции: `[{"id", "title", "aliases", "url", "format"}]`. Станция играет со своего
  сервера, как радио Яндекса (HLS). Поиск — по названию и синонимам; файл перечитывается на каждый запрос.
  Здесь — одна станция, ссылку на которую Яндекс сам отдал колонке (журнал ретрансляции, 31.10).
- `music/` — своя музыка: `Исполнитель - Название.mp3` (или `.ogg`, `.m4a`), папки — альбомы. Не в git.
- `tales/` — свои записи сказок и аудиокниг. Не в git.
- `tales/generated/` — сказки, которые рассказала модель голосом Алисы: шлюз сохраняет их звук, чтобы в
  следующий раз сыграть файлом (с паузой и «продолжи»). Не в git.

Права на музыку и записи — на владельце.
