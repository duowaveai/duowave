# Пакеты шлюза — встроенные

Пакеты в исходном виде, по папке на пакет: `manifest.json`, у плагина `backend.js`, при нужде `panel.js` и
`assets/`. Вид пакета — поле `kind` в манифесте: плагин, приложение, персонаж, тема. Как писать свой — в
[`docs/plugins/AUTHORING.md`](../docs/plugins/AUTHORING.md).

Пакеты, перечисленные в [`bundled.json`](bundled.json), вшиты в сборку шлюза (`gateway/src/plugins/bundled.rs`): при
старте он раскладывает их в `PACKAGES_DIR` с видом «встроенный» и в первый раз включает или нет — как сказано в
`bundled.json` («Список покупок» приходит выключенным: он забирает фразы у списка Яндекса). Встроенный можно выключить,
но не удалить — он обновляется вместе со шлюзом; править — через «Сделать свою копию» в пульте. Встроенные навыки
шлюза остаются запасными: плагин вернул `null` или упал — отвечает встроенный. `PLUGINS_BUNDLED=0` — не раскладывать.

| Пакет | Что делает |
|---|---|
| [`radio`](radio) | «включи радио джаз», `radio_search` и `radio_play` для «Мозга», источник радио для плеера шлюза, карточка в пульте. Свой список станций и каталог Radio Browser; станцию, на которой колонка молчит, помнит неделю и включает похожую |
| [`weather`](weather) | «какая погода», «какая погода завтра», `weather_now`; Open-Meteo, город из пульта |
| [`news`](news) | «новости», «новости спорта», `news_headlines`; ленты из пульта, без выбора — свой каталог лент по темам |
| [`music`](music) | «включи мою музыку …», источник музыки из `content/music` (право `content:music`) |
| [`tales`](tales) | «включи сказку …» из `content/tales`; «сочини сказку про …» — моделью шлюза (`llm.chat`) |
| [`games`](games) | «давай поиграем в города»: модель ведёт игру, колонка слушает дальше без «Алиса» (`continue`) |
| [`morning`](morning) | «утреннее шоу»: погода и новости из инструментов других плагинов (`tools.call`), потом своя музыка или радио |
| [`smart-home`](smart-home) | «включи свет на кухне», `smart_home_status`; через подключение Home Assistant шлюза (`smart_home`) |
| [`currency`](currency) | «курс доллара», «сколько стоит евро», `currency_rates`, виджет стола; курсы ЦБ (cbr-xml-daily.ru) |
| [`shopping`](shopping) | свой список покупок голосом, `shopping_list`, виджет стола; приходит выключенным |
| [`calendar`](calendar) | «что у меня сегодня», `calendar_events`, виджет стола; календарь по ссылке iCal (Google, Яндекс, iCloud) |

## Поставить свой пакет руками

Шлюз ищет пакеты в `PACKAGES_DIR` (по умолчанию `$DATA_DIR/packages`, без `DATA_DIR` — `data/packages`) в виде
`<id>/<версия>/`. Проще всего — мастерская или `duowave plugin install <папка>`; руками:

```sh
mkdir -p "$DATA_DIR/packages/hello"
cp -R hello "$DATA_DIR/packages/hello/1.0.0"
```

Пакет появляется в пульте («Дом» → «Пакеты») выключенным. Включает администратор — кнопкой в пульте или
`POST /api/v1/packages/hello/enable`. Новая версия — новая папка рядом (`hello/1.1.0`) и
`POST /api/v1/packages/hello/reload`: поднялась — работает она, нет — остаётся прежняя.
