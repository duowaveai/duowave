# Пульт «Стекло»

Веб-панель шлюза: состояние, кто отвечает, маршруты и «сказать через колонку».
Дизайн-система — [docs/design/glass](../docs/design/glass) (`DESIGN.md`). Пульт держит темы: «Стекло» (по
умолчанию, режимы «ночь» и «туман») и «Простор» (боковая панель); тема — данные в `src/shell/themes.ts`, контракт —
[THEMES.md](../docs/design/glass/THEMES.md). Выбор — «Дом» → «Доступ» → «Вид пульта».

## Разработка

```bash
pnpm --filter panel dev        # http://localhost:5173, /health и /debug проксируются на гейтвей
GATEWAY_URL=http://127.0.0.1:3000 pnpm --filter panel dev   # другой адрес гейтвея
```

## Сборка и прод

```bash
pnpm --filter panel build      # panel/dist — гейтвей раздаёт её на /panel (gateway/src/panel/)
pnpm --filter panel preview    # проверка прод-сборки без пересборки гейтвея
```

Гейтвей отдаёт панель на `/panel`: `panel/dist` вшивается в программу при сборке (`cargo build -p duowave`), поэтому
пульт собирается раньше шлюза; в отладочной сборке файлы читаются из папки.

## Данные

| Что | Откуда |
|---|---|
| Состояние, маршруты, счётчики | `GET /health` |
| Сессии колонки | `GET /debug/sessions` (нужен `DEBUG_API_ENABLED`) |
| «Пока не умеем» | `GET /debug/unsupported` |
| Сказать | `POST /debug/sessions/latest/say` |

Обновление — поллинг: `/health` каждые 3 с, debug-данные каждые 6 с.

## Ссылки внутрь пульта

Адрес после `#` называет раздел, вкладку и то, что в ней открыто: `#/<раздел>/<вкладка>/<id>?<параметры>`. Переходы
пишут адрес, назад и вперёд браузера его читают; ссылка, открытая до входа, ведёт туда после входа (`src/shell/links.ts`).

| Ссылка | Что откроет |
|---|---|
| `#/mind/characters/arthur?install` | «Мозг» → «Персонажи»: Артур, а не поставлен — его пакет с «Установить»; голосу нужна модель — окно «нужна модель» |
| `#/mind/characters/own` | «Собрать своего»: свой текст и свой голос |
| `#/house/packages/<пакет>` | «Дом» → «Пакеты»: пакет каталога в своём окне |
| `#/house/connectors/telegram` | «Дом» → «Коннекторы»: лист подключения |

Старые и короткие имена ведут туда же: `#/mind/character` → «Персонажи», `#/voice` → «Голос» (`models`).

## Структура

```
src/
  main.tsx          встроенное (builtin.tsx) в реестр, тема — до первой отрисовки
  app.tsx           данные шлюза и переходы (адрес следует за ними); раскладку рисует оболочка темы
  builtin.tsx       встроенное как плагин: пять разделов, «Сейчас отвечает» в home.cards и темы через definePlugin
  shell/            ядро без разделов: темы (themes.ts — данные, theme.ts — выбор), реестр и definePlugin
                    (registry.ts), разделы (sections.ts), слоты с границами ошибок (slot.tsx), оболочки
                    (tabbar-shell.tsx, sidebar-shell.tsx), контекст для экранов (context.ts), «Вид пульта»,
                    ссылки внутрь пульта (links.ts): #/<раздел>/<вкладка>/<id>?…
  ui/glass.css      элементы «Стекла»; цвета, шрифт, плотность и скругления — токены темы
  ui/utilities.css  классы вместо инлайн-стилей: отступы по плотности темы, цвета токенами
  ui/packages.css   персонажи и пакеты: галерея, аватары, тоны, каталог, разница текста
  ui/needs.tsx      окно «нужна модель» и метки готовности голоса — одно для персонажей и голосов
  ui/media.tsx      картинки и фразы-пробники шлюза по ключу входа (аватар, ▶ послушать)
  ui/brand.tsx      знак сервиса (Claude, Notion, Telegram…) в цвете бренда или текста
  brand-icons.ts    знаки сервисов и brand-icons.css — их цвета по темам (собирает scripts/brand-icons.mjs)
  icons.tsx         SVG-иконки из макетов
  api.ts            типизированный клиент (ответы шлюза обёрнуты в { message })
  capabilities.ts   каталог 22 способностей — как в gateway/src/skills/capabilities.rs гейтвея
  screens/          Колонка, Мозг (модели, персонажи, маршруты), Голос (голос, распознавание), Дом (коннекторы, шлюз,
                    пакеты, доступ), Журнал, шит «Сказать»; catalog.tsx — общий каталог пакетов всех видов,
                    characters.tsx — галерея персонажей на нём же
scripts/
  brand-icons.mjs   скачивает знаки с закреплённых версий Simple Icons и LobeHub Icons, считает контраст: pnpm icons
```

Источники и лицензии знаков — в [THIRD_PARTY.md](THIRD_PARTY.md).
