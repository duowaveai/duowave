# Что умеет колонка — для плагинов

Колонка — Яндекс Станция Лайт 2. Она слушает, говорит голосом Алисы и играет по ссылке (`audio_play`). Всё остальное
решает шлюз: маршрутизатор, «Мозг», навыки, плагины.

## Возможности (маршруты)

Фраза плагина служит одной возможности (`capability`): `radio`, `music`, `tales`, `weather`, `news`, `games`,
`smart_home`… — тогда действуют её маршрут («наш», Яндекс) и право человека (`use:radio`). Без возможности — общая
`plugins` (у гостей её нет). Управление колонкой — громкость, плеер, таймеры, будильники, «не беспокоить»,
Bluetooth, звонки — плагину не отдаётся никогда.

## Плеер

- `play` — очередь: «дальше» и «назад» листают её встроенным навыком, «пауза» и «стоп» — тоже встроенные.
- `format`: `HLS` для плейлиста `.m3u8`, `MP3` для потока любого другого кодека (как у Яндекса).
- `type`: `FmRadio` (живое радио, без перемотки), `Track`, `FairyTale`, `AudioBook`.
- Файл пакета — `path` из `assets/`: колонка берёт его с `/media/packages/<id>/…` шлюза.
- Файл семьи — `content` (`music/Альбом/1.mp3`, право `content:music` или `content:tales`): колонка берёт его с
  `/media/…` шлюза. Свой звук приложения — `stream`: шлюз пересылает его с `/stream/…` приложения.

| Что | Итог |

| «Студия 21», HLS | играет |
| «Радио Джаз», http | молчит, ошибки нет |

Шлюз записывает ответы колонки в журнал запроса («колонка начала играть», «молчит 5 с») и в журнал плагина
(`plugin_journal`), а плагину шлёт `player.started`, `player.silent`, `player.failed`.

## Память

Шлюз на колонке: 238 МБ всего, ~137 свободно, свопа нет. Бюджет плагинов — свободное минус 40 МБ запаса, каждый
включённый плагин занимает свой `budget.memoryMb`. Не помещается — не включится.
