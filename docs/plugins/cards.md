# Карточки и окошки

Виджет на столе пульта бывает двух видов (docs/plans/bus.md, «Пульт»).

- **Карточка** — данные. Функция `backend.js` отдаёт JSON из деталей пульта, пульт рисует их сам. Кода приложения
  в пульте нет: карточка лёгкая, безопасная и одинаковая на столе, в телефоне, в чате и голосом (`say`). Это вид
  по умолчанию.
- **Окошко** — своё рисование: `panel.js` (SDK пульта, docs/plugins/panel-sdk.d.ts). Оно работает в изолированном
  фрейме: без входа человека, без хранилища пульта, без сети (`connect-src 'none'`); в шлюз ходит только мостом
  пульта — к функциям своего `backend.js`, к своим картинкам, к своей MIDI-клавиатуре.

## Карточка или окошко: четыре вопроса

1. Нужно своё рисование — холст, игра, рисовалка, схема, которой нет среди деталей? (Красивый фон — не повод: его
   даёт `look`.)
2. Нужен ввод тоньше поля и кнопок — перетаскивание, клавиши на экране, MIDI-клавиатура?
3. Нужно движение чаще раза в секунду — анимация, ноты под пальцами?
4. Нужен звук в пульте?

На все «нет» — карточка. Хоть одно «да» — окошко. `check` предупреждает, когда `panel.js` только показывает строки
и кнопки: это может быть карточкой. Образец окошка-игры — встроенная «Неоновая змейка» (агенту — `docs`, тема `game`).

## Карточка в манифесте

```json
{
  "api": "^2",
  "contributes": {
    "panel": {
      "calls": ["today", "done", "add"],
      "cards": [
        { "id": "today", "title": "Дела на сегодня", "function": "today", "size": "small", "initial": true, "refreshS": 300 }
      ]
    }
  }
}
```

- `function` — функция `backend.js` из `contributes.panel.calls`: отдаёт карточку.
- `size` — `small` (по умолчанию) или `large`; `initial` — стоит на столе сразу; `refreshS` — перечитывать раз в
  столько секунд (не чаще раза в 10 с). Без него карточка перечитывается, когда меняются данные приложения
  (`host.kv.set`) — поэтому функция карточки ничего не пишет.
- `icon` — имя значка пульта: `weather`, `music`, `timer`, `list`, `coins`, `globe`, `heart`, `speaker`,
  `sparkle`, `package`.

## Ответ функции — карточка

Объект из деталей (или `{ "card": { … } }`). Любую деталь можно не давать. Деталь, которой нет в списке ниже,
пульт не рисует, а `check` называет.

```js
export function today() {
  const tasks = host.kv.get("tasks") ?? [];
  return {
    big: String(tasks.length),
    cap: "дел на сегодня",
    rows: tasks.map((task) => ({ text: task.text, mark: task.done ? "done" : "on", tap: "done", with: { id: task.id } })),
    input: { placeholder: "Новое дело", submit: "add" },
    empty: "Дел нет — отдыхайте",
    say: `На сегодня дел: ${tasks.length}.`,
  };
}
export function done({ id }) { /* … отметить … */ return today(); }
export function add({ text }) { /* … добавить … */ return today(); }
```

- Нажатие (`tap` у строки, плитки, кнопки, `submit` у поля, `tap` у выбора и переключателя) зовёт функцию из
  `contributes.panel.calls` с `with` (у поля — `{ text }`, у выбора — `{ id }`, у переключателя — `{ on }`).
  Ответ-карточка встаёт на место прежней; ответ не карточка — карточка перечитывается.
- Время в строках (`time`) — ISO: пульт пишет «14:05» сегодня, «12 нояб.» в другой день.
- `mark` у строки: `on`, `off`, `warn`, `done`.
- `say` — своя фраза для голоса и чата; без неё карточку перескажут по её деталям (заголовок, число, подпись).

## Вид карточки

Простая белая карточка скучна. `look` красит весь виджет вместе с шапкой: градиент из своих цветов, живая сцена пульта
за содержимым, своё фото фоном. Сцену рисует пульт — приложение только называет её, кода приложения в пульте нет.

```js
return {
  big: "+7°",
  cap: "дождь · ветер 4 м/с",
  tiles: [{ label: "завтра", value: "🌧 +5°" }],
  look: { scene: "rain", colors: ["#2d3e55", "#4b6987", "#6a8aa9"] },
};
```

- `scene` — что движется за карточкой (список ниже): погода — небо за окном (`sun`, `clouds`, `rain`, `storm`,
  `snow`, `fog`, ночью `stars`), музыка и радио — `waves` или `aurora`, покупки — `bubbles`, деньги и награды —
  `sparkles`, игры — `grid`. Сцена сама стоит, когда виджет вне экрана и при «меньше движения».
- `colors` — 1–3 цвета `#rrggbb` градиента фона; без них — цвета сцены. Подбирайте по смыслу и по времени: утро —
  тёплое, день — голубое, вечер — фиолетовое, ночь — тёмно-синее.
- `picture` — фото фоном: из своей папки `{name}` (`await host.files.download`) или из папки дома `{address}`; пульт
  затемняет его, чтобы текст читался.
- `ink` — цвет текста: `light` (по умолчанию, белый на цветном) или `dark` для светлого фона.
- Вид меняется вместе с данными: погода сменилась — сменилась сцена; функция карточки отдаёт его каждый раз.
