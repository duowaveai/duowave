# История и этапы

Часть описания устройства DuoWave — [ARCHITECTURE.md](../ARCHITECTURE.md). Пути `src/…` — от `gateway/`.

Шлюз — крейт `gateway/` на Rust (пакет и программа `duowave`, [README](../../gateway/README.md)). С 06.11.2026 он
заменил шлюз на Node/NestJS: тот удалён из дерева и остался в истории git под тегом `node-gateway-last`, а дерево
модулей крейта повторяет его `src/` в snake_case (правила — [gateway/PORTING.md](../../gateway/PORTING.md), ход
переноса — план). Пути `src/…` ниже — от `gateway/`.

## Этапы

1. **Протокол и наблюдаемость** (готово): ws-сервер, AAPI-кодек, сессии, журнал, запись
   звука, таймлайн, отладочный API.
2. **Звук и распознавание** (готово): Ogg/Opus → PCM, усиление по «Алисе», Silero VAD, конец
   фразы, промежуточные `AsrResult` с текстом на лету, ASR через OpenAI-совместимый сервис
   (GigaAM в `asr-server/` или облако), тихая речь (шёпот) без VAD, повтор записей.
3. **Диалог** (готово): LLM (Claude, OpenAI-совместимый, echo) со стримингом по фразам,
   системный промпт из файла, время колонки, история по устройству.
4. **Синтез и ответ** (готово, проверено вживую 31.10.2026 в режиме echo: ответ голосом Алисы
   колонка доиграла до конца, звук через ~0,9 с после финального текста): поток ответа колонке,
   `should_listen`, отмена; озвучка голосом Алисы через нашу сессию с Яндексом, `TtsGenerate`
   от колонки. Свой синтез — позже.
5. **Сеть**: колонка ходит в Яндекс только через наш сервер — план.
6. **Возможности Алисы** (реализовано 01.11.2026, ждёт живых проверок —
   список): этапы 0–8 и 10 плана интеграции:
   - ранний ответ с джинглом, режимы слушания, профили моделей;
   - маршрутизатор с быстрыми правилами и моделью с инструментами, «пока не умею»;
   - одна сессия с Яндексом: push и маршрут «Яндекс» с переадресацией потоков;
   - свои таймеры на типизированных командах; медиасервер;
   - шёпот, погода, новости, умный дом, игры, напоминания;
   - свои звонки; свой синтез; служба launchd.

   Подробности: [README](../../README.md), возможности.
7. **Дальше**: закрытый выход колонки (этап 9, отложен), перебивание (интонационное — штатная
   функция колонки), JSON-протокол.
8. **Перенос на Rust** (06.11.2026): тот же шлюз одной программой `duowave` с пультом внутри, своя база с
   миграциями по номерам, сборка для самой колонки, обновления; Node-шлюз удалён (тег `node-gateway-last`) —
   план и ход работ.
9. **Плагины и темы** (07.11.2026, этапы 1–10 плана): ядро не меняется, навыки, инструменты «Мозга», источники
   медиа, вкладки пульта и темы приходят пакетами; встроенные навыки — встроенными плагинами; мастерская, каталог,
   приложения — план, раздел [«Пакеты и плагины»](packages.md).
10. **«Дом» и помощники, блок 1** (15–16.11.2026): список помощников по порядку, договор помощника, регулятор «Что
    может уходить из дома», «Где сейчас», «Мозг» без помощника, встроенный помощник, связь из-за роутера; программа
    колонки хранит пульт сжатым — план, раздел [«Где работает шлюз»](placement.md).
