# Проверка вручную: дом и его устройства

Как пройти руками то, что сделано по плану «Дом и устройства»: один пульт дома,
центр и Турбо, копия дома на компьютере, Telegram дома, приложения дома, первые шаги. Глазами пользователя: что
нажать и что должно получиться. Около часа; колонка перезапустит программу DuoWave один раз (минута без голоса).

⚠️ Это меняет колонку: программа DuoWave в `/data/opt/duowave` заменяется сборкой из `main`. Путь назад — копия
прежней программы из шага 1 (раздел «[Если что-то не так](#если-что-то-не-так)»). Каждый шаг на колонке — только
после «да» владельца.

В командах:

- `<проект>` — папка репозитория;
- `<копии>` — папка для копий вне git, например `~/station-backup-<дата>`;
- `station` — SSH к колонке: псевдоним в `~/.ssh/config` (`root`, порт 2222) или `root@<колонка> -p 2222`.

## 0. Сборка (один раз)

Обе программы — из одного коммита `main`, с теми же адресами лент, что у выпуска:

```bash
cd <проект>
export DUOWAVE_PACKAGES_FEED=https://packages.duowave.app/catalog.json
pnpm --filter panel build
DUOWAVE_UPDATE_FEED=https://updates.duowave.dev/latest.json cargo zigbuild -p duowave --target aarch64-unknown-linux-musl --profile station --no-default-features --features station
cd desktop/src-tauri && cargo tauri build --bundles app
```

- Колонке — `target/aarch64-unknown-linux-musl/station/duowave`.
- Mac — `desktop/src-tauri/target/release/bundle/macos/DuoWave.app`. Подписи Apple нет: первый запуск — правой
  кнопкой → «Открыть» или «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

## 1. Колонка: посмотреть и снять копии (только чтение)

Колонка ничего не меняет на этом шаге. Что работает и сколько места:

```bash
ssh -n station 'cat /data/opt/duowave/gateway-bin; cat /data/opt/duowave/managed-by; df -k /data | tail -1; grep MemAvailable /proc/meminfo'
```

Должно быть: программа — `/data/opt/duowave/bin/duowave`, ставил её `pc`, свободно в `/data` больше размера новой
программы с запасом 5 МБ. Иначе — остановиться: колонку ставили иначе, этот лист для неё не годится.

Копии — прежняя программа, настройки шлюза колонки и её база (в ней личное: держать вне git, удалить после проверки):

```bash
mkdir -p <копии> && cd <копии>
ssh -n station 'cat /data/opt/duowave/bin/duowave' > duowave-old && shasum -a 256 duowave-old
ssh -n station 'sha256sum /data/opt/duowave/bin/duowave'
ssh -n station 'tar -cf - -C /data/opt/duowave/gateway .env state' > gateway.tar
```

Две суммы совпадают. Миграция `0016` — на копии базы колонки, не на самой колонке:

```bash
mkdir -p db && tar -xf gateway.tar -C db
cd <проект>/gateway && DUOWAVE_DB_COPY=<копии>/db/state cargo test -p duowave --lib home::copy -- --ignored
```

Тест проходит: миграция встала, люди и настройки на месте, очередь правок работает.

## 2. Колонка: новая программа

⚠️ Колонка на минуту без голоса, пока программа перезапускается. Путь назад — шаг «[Если что-то не так](#если-что-то-не-так)».

```bash
cd <проект>
shasum -a 256 target/aarch64-unknown-linux-musl/station/duowave
ssh station 'cat > /data/opt/duowave/bin/duowave.new' < target/aarch64-unknown-linux-musl/station/duowave
ssh -n station 'sha256sum /data/opt/duowave/bin/duowave.new'
```

Суммы совпадают — тогда замена и перезапуск:

```bash
ssh -n station 'chmod 755 /data/opt/duowave/bin/duowave.new && mv /data/opt/duowave/bin/duowave.new /data/opt/duowave/bin/duowave && setsid sh /data/opt/duowave/gateway.sh restart </dev/null >/dev/null 2>&1'
```

Через минуту пульт колонки `http://<колонка>:8790/panel` открывается, «Алиса, сколько времени?» отвечает.

## 2а. Или начисто: колонка без DuoWave

Весь путь нового человека: на колонке только root (DuoWave снят её же `sh /data/opt/duowave/uninstall.sh`), на Mac —
пустая папка данных. Шаги 1–2 тогда не нужны: программу колонки ставят первые шаги. Тестовая сборка не несёт её в себе
(в выпуске она внутри, с подписью ключа выпусков), и без двух строк ниже первые шаги поставили бы колонке программу
выпуска той же версии из ленты. Архив и одноразовый ключ:

```bash
mkdir -p payload && cp target/aarch64-unknown-linux-musl/station/duowave payload/duowave
COPYFILE_DISABLE=1 tar -czf duowave-station-aarch64.tar.gz -C payload duowave
cargo tauri signer generate --ci -p "" -w test.key -f
cargo tauri signer sign -f test.key -p "" duowave-station-aarch64.tar.gz
```

В `.env` папки данных Mac, рядом с `PORT=7780`, — `STATION_PAYLOAD_FILE=<путь к архиву>` и
`UPDATE_PUBKEY=<содержимое test.key.pub>`. После проверки обе строки убрать.

Что увидит человек: «Пароль» → «Ваш дом» (колонка — «станет центром», «Этот компьютер» — «Турбо, пока включён») →
«Колонка»: «Проверим колонку» (только чтение по SSH) → «Что изменится» → «Подключить» → «Подключаю колонку»
(подключение, перенос DuoWave на колонку, её перезагрузка; ждать не обязательно) → «Кто отвечает на колонке?»
(«Как раньше · Вместе · Своё» и чей ИИ) → «Персонаж» → «Попробуйте сказать» → MagicPlace. Дальше — раздел 4.

## Если что-то не так

Колонка — прежняя программа обратно (база остаётся: прежняя версия читает только знакомые ей столбцы):

```bash
cd <копии>
ssh station 'cat > /data/opt/duowave/bin/duowave.new' < duowave-old
ssh -n station 'sha256sum /data/opt/duowave/bin/duowave.new'
ssh -n station 'chmod 755 /data/opt/duowave/bin/duowave.new && mv /data/opt/duowave/bin/duowave.new /data/opt/duowave/bin/duowave && setsid sh /data/opt/duowave/gateway.sh restart </dev/null >/dev/null 2>&1'
```

Сумма совпадает с `duowave-old` из шага 1. Mac — закрыть тестовое приложение, открыть DuoWave из `/Applications`.

Журналы: Mac — `~/Library/Logs/app.duowave.desktop/gateway.log`; колонка — `/data/opt/duowave/gateway/gateway.log`
(читать тоже после «да»).

## Уборка

Копии базы колонки — личные данные: удалить `<копии>/db` и `<копии>/gateway.tar`, когда проверка пройдена и колонка
работает.

Тестовое приложение при первом запуске на чистой папке данных включает «Запускать при входе» на себя. Вернулись к
DuoWave из `/Applications` — в меню его значка выключить и снова включить «Запускать при входе».
