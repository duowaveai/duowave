# Темы пульта: контракт

Тема — данные, а не код: палитры двух режимов, плотность, шрифт и скругления. Её приносят тем же путём, что разделы и
виджеты: `definePlugin({ id, sections, slots, themes })`. Встроенная тема одна — «Минимал» (`panel/src/builtin.tsx`);
«Стекло», «Простор» и «Минимал · панель» удалены 10.11.2026 (план стола): каждый новый элемент
иначе рисовать дважды. Темы пакетов перекрашивают «Минимал». Вид — стол и док или боковая панель — выбирает человек
отдельно от темы.

## Тема

```ts
// panel/src/shell/themes.ts
interface Theme {
    id: string;                       // 'minimal', 'glass', 'prostor', 'radio-browser.dusk'…
    title: string;                    // в выборе темы
    about: string;                    // одна строка: чем отличается
    modes: { dark: string; light: string };          // названия режимов: «Ночь» и «Туман»
    modeNotes?: { dark?: string; light?: string };   // строка под выбором режима, если режиму есть что сказать
    defaultMode?: 'dark' | 'light';   // режим, пока человек не выбрал; без него — как у системы
    look?: string;                    // материал: всегда 'minimal' (поле — для старых пакетов)
    palette: { dark: Palette; light: Palette };       // CSS-токены без «--»
    layout: string;                   // вид, который тема советует: 'desk' | 'sidebar' ('tabbar' — стол); выбирает человек
    density: number;                  // множитель отступов: 1 — как в DESIGN.md
    font: string;                     // CSS font-family; файлы шрифта приносит тема
    radius: { panel: number; large: number; bar: number };   // px: карточки; шит и боковая панель; панель вкладок
    colors?: { dark?: Anchors; light?: Anchors };    // три цвета режима — пульт достроит палитру (ниже, «Три цвета»)
    backdrop?: Backdrop | { dark?: Backdrop | null; light?: Backdrop | null };   // рисованный фон (ниже, «Фон»)
}
```

Светлое и тёмное — режим внутри темы, а не две темы. Пульт помнит в браузере выбор человека (`panel-theme`,
`{ v: 2, id, mode }`, `null` — «как по умолчанию») и вид (`panel-view`: `desk` | `sidebar`), пишет режим в
`glass-theme` для старых сборок. Выбор удалённой темы — тема по умолчанию; у «Простора» и «Минимал · панели» ещё и
вид «Боковая панель», если вид не выбран.

## Материал

Материал один — `minimal`: плоские тёплые карточки, белые листы, капсулы и точки статусов (`ui/glass.css` — базовые
элементы, `ui/minimal.css` — материал, `ui/desk.css` — стол, док, окна и виджеты; DESIGN.md → «Тема „Минимал“»).
Пульт ставит его на `<html data-look>`. Палитра темы-пакета ложится поверх палитры «Минимала».

## Три цвета

Проще всего — дать на каждый режим три цвета, остальное пульт достроит сам (`panel/src/shell/theme-colors.ts`):

```json
"colors": {
    "dark":  { "bg": "#0B1026", "text": "#EEF0FF", "accent": "#FFD36E" },
    "light": { "bg": "#F4F1FF", "text": "#1B1A33", "accent": "#5B4BD6" }
}
```

- `bg` — фон страницы, `text` — основной текст, `accent` — главное действие («Сказать»). Все три — `#rrggbb`.
- Из них пульт выводит карточки, листы и меню, линии, подложки, поля, выбор, тени, вторичный и приглушённый текст,
  текст на акценте (чёрный или белый — что читается) и акцент как текст (сдвинутый к `text`, пока не прочтётся).
- Цвета смысла — кто отвечает, слои памяти, беда — не из трёх цветов: их пульт берёт у светлого или тёмного
  «Минимала» по яркости `bg`.
- Текст должен читаться на фоне: контраст `text` к `bg` — от 4,5, иначе проверка мастерской и установка откажут.
  Акцент не должен сливаться с фоном.
- Режим без `colors` — палитра «Минимала» этого режима. `palette` (ниже) ложится поверх выведенного: им правят
  отдельный токен, если вывод не понравился.

Голосом так и просят: «сделай тему: кремовая, с зелёным» — агенту хватает трёх цветов на режим.

## Фон

Рисованный фон за столом: градиент и до трёх живых сцен пульта поверх него. Сцены те же, что у карточек
([cards.md](../../plugins/cards.md), «Вид карточки»): `sun`, `clouds`, `rain`, `storm`, `snow`, `fog`, `stars`, `aurora`,
`waves`, `bubbles`, `sparkles`, `grid`. Рисует их пульт, тема только называет — кода в теме нет, и чужая тема из
каталога ничего, кроме фона, нарисовать не может.

```json
"backdrop": {
    "dark":  { "layers": [{ "scene": "stars" }, { "scene": "aurora", "opacity": 0.5 }], "colors": ["#070b2a", "#211c57"], "dim": 0.15 },
    "light": null
}
```

- Один фон на оба режима — сразу `{ "scene": "snow" }`; свой у каждого — `{ "dark": …, "light": … }`, `null` — в этом
  режиме фона нет.
- `scene` — один слой; `layers` — 1–3 слоя `{ scene, opacity? }` (0,1–1), рисуются по порядку, верхний — последний.
- `colors` — 1–3 цвета градиента под сценами; без них — ровный `bg` режима. Держите их близко к `bg`: надписи на
  столе (часы, подписи колонки) стоят прямо на фоне.
- `dim` — 0–0,8: насколько притушить фон цветом `bg`, если сцена слишком яркая для надписей.
- Сцены рисуют светлым; на светлом фоне пульт переворачивает их в тёмное того же оттенка — снег становится серым,
  звёзды тёмными. Ночные сцены (`stars`, `aurora`) красивее в тёмном режиме.
- Карточки, окна и док над фоном — свои, непрозрачные: фон виден на столе между ними. При «меньше движения» и в
  скрытой вкладке сцена стоит.

## Палитра

Тема-пакет приносит только то, что меняет: недостающие токены берутся у «Минимала» (или у выведенных из трёх цветов).

```ts
palette: {
    dark: { bg: '#0B120E', accent: '#6EE7A8', 'accent-text': '#6EE7A8' },
    light: { bg: '#F1F7F3', accent: '#1F9D63', 'accent-text': '#137A4B' },
}
```

| Группа | Токены |
|---|---|
| Основа | `bg`, `aurora` (сияние — фон страницы), `text`, `sub` |
| Стекло | `glass-bg`, `glass-border`, `glass-hi`, `glass-shadow`, `glass-blur`; плотное — `strong-*`; `menu-bg` |
| Линии и подложки | `divider`, `track`, `icon-bg`, `scrim`, `grabber` |
| Действие | `accent`, `on-accent`, `accent-text`, `talk-shadow` |
| Исполнители | `bar-*`, `pill-*-fg`, `pill-*-bg`, `soft-*` для own / yandex / agent / off; `dot-offline` |
| Выбор | `seg-on-bg`, `seg-on-fg`, `seg-off-fg`, `radio-on-bg`, `radio-on-fg`, `radio-off` |
| Дашборд | `label-*`, `node-hi`, `node-shadow`, `on-badge`, `orbit`, `orbit-hi`, `station-shadow` |

Смысл цвета в данных у всех тем один (DESIGN.md, The Who-Answers Rule): лайм — свой, янтарь — Яндекс и облако,
фиолет — агент, сланец — выключено, коралл — беда. Тема может сдвинуть оттенок, но не поменять смысл. В светлом
режиме выбор — чернилами, а не лаймом (The Ink-Selection Rule).

Пульт пишет токены выбранной темы правилом `html:root[data-theme] { … }` в `<style id="theme">`. Тема по умолчанию
вшита в `index.html` при сборке (`vite.config.ts`), а выбранная кэшируется в `panel-theme-css`: первая отрисовка —
сразу в её цвета, без мигания. Значения — данные: `;`, `{`, `}` и `<` в них отбрасываются.

## Плотность, шрифт, скругления

- **Плотность** множит отступы и промежутки: `--s-*` и классы `ui/utilities.css` (`gap-*`, `m*-*`, `p*-*`,
  `card-list`, `list-row`, `pill-btn`) считаются как `calc(Npx * var(--density))`. Высоту нажимаемых целей
  (44 точки), размеры значков и рамки плотность не трогает.
- **Шрифт** — `--font`. Цифры остаются моноширинными (`tabular-nums`) в любой теме.
- **Скругления** — `--r-panel` (карточки), `--r-panel-desk` (шит, боковая панель, окно), `--r-bar` (панель
  вкладок, полоса сверху). Капсулы и круги остаются капсулами и кругами.

## Виды (оболочки)

Оболочка знает, где навигация, верхняя строка и кнопка «Сказать», и не знает, какие разделы есть: пункты навигации
строит `app.tsx` из реестра (`panel/src/shell/sections.ts`) и роли пульта. Вид ставится на `<html data-shell>`, роль
— на `<html data-role>` (`gateway` | `helper`): у помощника рамка (верхняя строка, док, боковая панель) тёмная.

| Вид | Что | Где |
|---|---|---|
| `desk` | стол: колонка посередине, виджеты вокруг; тонкая верхняя строка с ролью; док снизу — разделы, круг «Сказать», «Ещё» и «+»; разделы — окнами поверх стола; на телефоне — лента | `shell/desk-shell.tsx`, `screens/desk.tsx` |
| `sidebar` | от 900 точек — боковая панель: роль, колонка, капсула «Сказать через колонку», разделы; уже — полоса сверху с меню, колонкой и кругом «Сказать»; стол — столбцом | `shell/sidebar-shell.tsx` |

Раздел с `nav: 'more'` (журнал) в доке — в «Ещё»; в боковой панели он ниже черты. У помощника в доке слева своё
(стол, модели, мастерская), справа — разделы колонки.

## Разделы и слоты

```ts
definePlugin({
    id: 'radio-browser',
    sections: [{ id: 'radio', title: 'Радио', icon: IconMusic, Screen: RadioScreen, order: 45, permission: 'station.view' }],
    slots: {
        'home.cards': [{ id: 'now-playing', Component: NowPlaying }],
        'house.tabs': [{ id: 'stations', title: 'Станции', icon: IconMusic, Component: StationsTab }],
    },
    themes: [DUSK],
});
```

| Слот | Где | Что получает вклад |
|---|---|---|
| `desk.widgets` | стол: виджет с `title`, `icon`, `size` (`small` \| `large`), `source`, `initial`, `roles` | — |
| `home.cards` | стол: карточка большим виджетом в своей рамке | — |
| `header.actions` | шапка (в боковой панели — внизу, рядом со сменой режима) | — |
| `house.tabs` | «Дом», вкладки после встроенных; нужны `title` и `icon` | — |
| `say.extras` | шит «Сказать через колонку», под полем | `speakable` |

Каждый вклад и каждый раздел живут в своей границе ошибок: упавший вклад прячется, вкладка и раздел говорят, что
не открылись, соседи и навигация работают. Чей вклад упал — в консоли браузера (`Пульт: «плагин.вклад» упал…`).
`header.actions` и `home.cards` без вкладов ничего не рисуют.

## Как проверить тему

Открыть «Настройки» → «Оформление» → «Вид пульта», выбрать тему, переключить режим и вид. Тема с фоном — посмотреть
стол в обоих режимах: надписи на фоне читаются, сцена не мешает. Пройти все разделы и шиты
на ширине телефона (375) и компьютера, в обеих ролях. Тема без своего плагина (его выключили или он ещё не загрузился) откатывается на тему
по умолчанию («Минимал»), а выбор человека сохраняется: плагин вернулся — вернулась и тема.
