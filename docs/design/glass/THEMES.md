# Темы пульта: контракт

Тема — данные, а не код: палитры двух режимов, оболочка (раскладка), плотность, шрифт и скругления. Её приносят тем
же путём, что разделы и карточки: `definePlugin({ id, sections, slots, themes })`. Встроенные «Минимал» (по
умолчанию с 08.11.2026), «Минимал · панель», «Стекло» и «Простор» регистрирует `panel/src/builtin.tsx`, плагины с шлюза потом будут регистрировать свои так же
(`docs/plans/plugins.md`, этапы 1 и 5). Как выглядит «Стекло» и почему — [DESIGN.md](../../../DESIGN.md).

## Тема

```ts
// panel/src/shell/themes.ts
interface Theme {
    id: string;                       // 'minimal', 'glass', 'prostor', 'radio-browser.dusk'…
    title: string;                    // в выборе темы
    about: string;                    // одна строка: чем отличается
    modes: { dark: string; light: string };          // названия режимов: «Ночь» и «Туман»
    modeNotes?: { dark?: string; light?: string };   // строка под выбором режима, если режиму есть что сказать
    defaultMode?: 'dark' | 'light';   // режим, пока человек не выбрал; без него — как у системы
    look?: string;                    // материал: 'glass' | 'minimal'; незнакомый — 'glass'
    palette: { dark: Palette; light: Palette };       // CSS-токены без «--»
    layout: string;                   // оболочка: 'tabbar' | 'sidebar'; незнакомая — 'tabbar'
    density: number;                  // множитель отступов: 1 — как в DESIGN.md
    font: string;                     // CSS font-family; файлы шрифта приносит тема
    radius: { panel: number; large: number; bar: number };   // px: карточки; шит и боковая панель; панель вкладок
}
```

Светлое и тёмное — режим внутри темы, а не две темы. Пульт помнит в браузере выбор человека (`panel-theme`,
`{ v: 2, id, mode }`, `null` — «как по умолчанию») и пишет режим в `glass-theme` для старых сборок. Запись прежних
сборок `{ id: 'glass' }` — не выбор (её писал сам пульт): тогда стоит тема по умолчанию в своём `defaultMode`.

## Материал

`look` — как выглядят поверхности и элементы; пульт ставит его на `<html data-look>`. `glass` — стекло (`glass.css`,
DESIGN.md), `minimal` — плоские тёплые карточки, белые листы, капсулы и точки статусов (`ui/minimal.css`, DESIGN.md →
«Тема „Минимал“»). Палитра темы-пакета ложится поверх палитры темы своего материала: `look: 'minimal'` берёт
недостающие токены у «Минимала», остальные — у «Стекла».

## Палитра

Каждый режим задаёт все токены, которые читают `glass.css` и экраны. Проще всего взять «Стекло» и поменять своё:

```ts
palette: {
    dark: { ...GLASS.palette.dark, bg: '#080B12', aurora: 'radial-gradient(…), …' },
    light: { ...GLASS.palette.light, bg: '#EEF2F6' },
}
```

| Группа | Токены |
|---|---|
| Основа | `bg`, `aurora` (сияние — фон страницы), `text`, `sub` |
| Стекло | `glass-bg`, `glass-border`, `glass-hi`, `glass-shadow`, `glass-blur`; плотное — `strong-*`; `menu-bg` |
| Линии и подложки | `divider`, `track`, `icon-bg`, `scrim`, `grabber` |
| Действие | `accent`, `on-accent`, `accent-text`, `talk-shadow` |
| Исполнители | `bar-*`, `pill-*-fg`, `pill-*-bg`, `soft-*` для own / yandex / agent / off; `dot-offline` |
| Выбор | `seg-on-bg`, `seg-on-fg`, `seg-off-fg`, `radio-on-bg`, `radio-on-fg`, `radio-off` |
| Дашборд | `label-*`, `node-hi`, `node-shadow`, `on-badge`, `orbit`, `orbit-hi`, `station-shadow` |

Смысл цвета в данных у всех тем один (DESIGN.md, The Who-Answers Rule): лайм — свой, янтарь — Яндекс и облако,
фиолет — агент, сланец — выключено, коралл — беда. Тема может сдвинуть оттенок, но не поменять смысл. В светлом
режиме выбор — чернилами, а не лаймом (The Ink-Selection Rule).

Пульт пишет токены выбранной темы правилом `html:root[data-theme] { … }` в `<style id="theme">`. Тема по умолчанию
вшита в `index.html` при сборке (`vite.config.ts`), а выбранная кэшируется в `panel-theme-css`: первая отрисовка —
сразу в её цвета, без мигания. Значения — данные: `;`, `{`, `}` и `<` в них отбрасываются.

## Плотность, шрифт, скругления

- **Плотность** множит отступы и промежутки: `--s-*` и классы `ui/utilities.css` (`gap-*`, `m*-*`, `p*-*`,
  `card-list`, `list-row`, `pill-btn`) считаются как `calc(Npx * var(--density))`. Высоту нажимаемых целей
  (44 точки), размеры значков и рамки плотность не трогает.
- **Шрифт** — `--font`. Цифры остаются моноширинными (`tabular-nums`) в любой теме.
- **Скругления** — `--r-panel` (карточки), `--r-panel-desk` (шит, боковая панель, окно), `--r-bar` (панель
  вкладок, полоса сверху). Капсулы и круги остаются капсулами и кругами.

## Оболочки

Оболочка знает, где навигация, шапка и кнопка «Сказать», и не знает, какие разделы есть: список приходит из
реестра (`panel/src/shell/sections.ts`). Имя оболочки ставится на `<html data-shell>` — по нему стили знают
раскладку.

| `layout` | Что | Где |
|---|---|---|
| `tabbar` | шапка с колонкой; плавающая панель вкладок снизу, круг «Сказать» посередине | `shell/tabbar-shell.tsx` |
| `sidebar` | от 900 точек — боковая панель: колонка, капсула «Сказать через колонку», разделы, кнопки шапки; уже — полоса сверху с меню, колонкой и кругом «Сказать», разделы выезжают слева | `shell/sidebar-shell.tsx` |

Раздел с `nav: 'more'` (журнал) в панели вкладок не показывается — туда ведут ссылки; в боковой панели он ниже
черты. Панель, прижатую к низу экрана, оболочка помечает `data-dock="bottom"`: дашборд считает высоту сцены до
неё.

## Разделы и слоты

```ts
definePlugin({
    id: 'radio-browser',
    sections: [{ id: 'radio', title: 'Радио', icon: IconMusic, Screen: RadioScreen, order: 45, permission: 'station.view' }],
    slots: {
        'home.cards': [{ id: 'now-playing', Component: NowPlaying }],
        'house.tabs': [{ id: 'stations', title: 'Станции', icon: IconMusic, Component: StationsTab }],
    },
    themes: [DUSK],
});
```

| Слот | Где | Что получает вклад |
|---|---|---|
| `home.cards` | «Колонка», под встроенными карточками | — |
| `header.actions` | шапка (в боковой панели — внизу, рядом со сменой режима) | — |
| `house.tabs` | «Дом», вкладки после встроенных; нужны `title` и `icon` | — |
| `say.extras` | шит «Сказать через колонку», под полем | `speakable` |

Каждый вклад и каждый раздел живут в своей границе ошибок: упавший вклад прячется, вкладка и раздел говорят, что
не открылись, соседи и навигация работают. Чей вклад упал — в консоли браузера (`Пульт: «плагин.вклад» упал…`).
`header.actions` и `home.cards` без вкладов ничего не рисуют: раскладка «Стекла» не меняется.

## Как проверить тему

Открыть «Дом» → «Доступ» → «Вид пульта», выбрать тему, переключить режим. Пройти все разделы и шиты на ширине
телефона (375) и компьютера. Тема без своего плагина (его выключили или он ещё не загрузился) откатывается на тему
по умолчанию («Минимал»), а выбор человека сохраняется: плагин вернулся — вернулась и тема.
